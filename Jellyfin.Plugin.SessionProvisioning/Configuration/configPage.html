Hex-encoded SHA-256 hash of the provisioning secret. The plaintext secret is never stored here and cannot be recovered from the server. While this is empty or malformed, session provisioning is disabled.
Generate a secret and its hash on a trusted machine:
SECRET=$(openssl rand -base64 32 | tr '+/' '-_' | tr -d '=')
echo "$SECRET" — give this to the provisioning service only
printf '%s' "$SECRET" | sha256sum — paste the hash above
Callers must present the secret in the X-Session-Provisioning-Secret header and hold Jellyfin administrator authorization. Note that any valid Jellyfin API key counts as administrator, so this secret is what keeps provisioning limited to your provisioning service.
